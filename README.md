# EmberFat

Stereo saturation VST3 by **eM4**.

[Download EmberFat v0.3.0 for Windows](https://github.com/0xPRISMM/EmberFat/releases/tag/v0.3.0). The release includes the installer, a VST3 ZIP, and SHA256 checksums.

![Current EmberFat interface](emberfat-ui.png)

The current interface uses the supplied amber background, silver controls and six tiger stages. OUTPUT is smaller and aligned farther right.

The 0.3.0 processor adds much stronger linked compression, saturation and rounded clipping, smooth controls and 8x oversampling. OUTPUT now goes up to +24 dB, and the VST3 is classified as a general audio effect. See the [current source and build instructions](https://github.com/0xPRISMM/EmberFat/tree/codex/smooth-saturation) and [DSP review](https://github.com/0xPRISMM/EmberFat/blob/codex/smooth-saturation/docs/DSP_REVIEW_0_3.md).
