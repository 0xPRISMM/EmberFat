# EmberFat

Stereo saturation VST3 by **eM4**.

![Current EmberFat interface](emberfat-ui.png)

The current interface uses the supplied amber background, silver controls and six tiger stages. OUTPUT is smaller and aligned farther right.

The 0.2.0 processor adds smooth knob changes, crossfaded bypass and 4x oversampling. See the [current source and build instructions](https://github.com/0xPRISMM/EmberFat/tree/codex/smooth-saturation) and [DSP review](https://github.com/0xPRISMM/EmberFat/blob/codex/smooth-saturation/docs/DSP_REVIEW.md).
